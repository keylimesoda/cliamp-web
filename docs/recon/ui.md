Column availability is calculated for the full list, not per row.\n- **Ordering:** regular playlist order or shuffled play order; shuffled rows before cursor are already played, rows after it are upcoming. Turning shuffle off restores sequential track order while retaining current track. Track moves are refused during shuffle (`Turn off shuffle to move tracks`). Main playlist provides one-row move up/down via Shift+Up/Down.\n- **Playlist-manager track sort cycle:** `track` (track number, title, path); `title` (implementation comparator); `artist`; `album`; `artist+album`; `path`. Comparisons case-insensitive and stable. Display/documented cycle order exactly: `track`, `title`, `artist`, `album`, `artist+album`, `path`. Sort saves and resets cursor/scroll to top.\n- **Queue add/toggle:** main playback `a` toggles selected playlist track in queue; provider-browser final-track `q` appends highlighted track to playlist and queues it; search-result `q` queues selected track; radio/podcast list-specific flows described in §§9–10. Queue API holds track indices in ordered array; queue order is play-next order and items are dequeued before ordinary playlist progression. Repeated queue entries are permitted. Main queue operation is toggle; queue-manager operations directly modify entries.\n- **Queue remove/reorder/clear:** `A` opens queue manager. `d` removes highlighted queue entry; `Shift+Up/Down` moves it one position; `c` clears queue and closes manager; Ctrl+Z restores the prior queue snapshot after clear/remove. Queue has no separate insert-index UI; adding via play-next appends to queue. Saved playlist picker `p` adds tracks at playlist start, which is distinct from queue insertion.\n- **Shuffle modes:** exactly two states, `Off` and `On` (`ToggleShuffle`). On builds/retains a randomized order with current track preserved; playlist display becomes play order; adding tracks in shuffle mode mixes them into upcoming order; off restores original track order, current track preserved.\n- **Repeat modes:** `RepeatOff` (display `Off`), `RepeatAll` (`All`), `RepeatOne` (`One`). Cycle is Off → All → One → Off. Repeat All wraps end to beginning and previous from beginning to end; Repeat One advances to same current track, except queued tracks are consumed first.\n\n## 5. Lyrics\n\n- `y` toggles lyrics; current track is queried. Track-start while overlay open starts lookup automatically. Local embedded track-tag lyrics take precedence; parser preserves timestamped LRC; plain embedded text becomes one zero-time line per input line. Empty lines display as `♪`.\n- Spotify path with configured signed-in Spotify lyrics-capable provider: fetch Spotify track lyrics first (10-second context timeout); failure/empty silently falls back to generic lookup. Generic `lyrics.Fetch(artist,title)` tries LRCLIB then NetEase Cloud Music. Lookup query is cleaned of bracketed/parenthesized text and trailing official/video/audio labels. YouTube/SoundCloud title `Artist - Song` overrides uploader/artist with split title. Stream ICY `StreamTitle` split on ` - ` provides lookup artist/title when possible.\n- LRCLIB endpoint is `https://lrclib.net/api/search?q=<QueryEscape(query)>`; uses synced lyrics from first result containing them, otherwise first result plain lyrics. NetEase searches then fetches lyric. Both response bodies capped at 2 MiB; shared HTTP client timeout 10 seconds. (Provider HTTP details beyond lyric sources are not included.)\n- LRC timestamp syntax accepted by parser: `[minutes:seconds.fraction]text`; minutes at least two digits, seconds exactly two, fraction two or three digits. Two fractional digits mean hundredths and are multiplied by 10 ms; three are milliseconds. Non-timestamp metadata rows are ignored. Line order is input order. Plain lines have `Start=0`.\n- Synced mode requires timestamped lines plus song-relative position: ordinary local/on-demand tracks; finite-duration yt-dlp tracks; streams with provider metadata unless marked live. Live/ICY and YouTube Live are manually scrolled even when lyrics carry timestamps. Active timestamp line is greatest start ≤ playback position plus offset; centered around active line within visible rows. `j`/`k` and arrows scroll nonsynced lines. `[`/`]` shift offset −/+250 ms; persisted config key `lyrics_offset_ms`; clamps to ±10 seconds. `r` retries; Esc/y closes.
